Kesehatan data dan legenda

TERUKURSetiap angka di halaman ini berasal dari baris-baris berikut: sumber, frekuensi, tanggal data terakhir, dan statusnya.
Frekuensi: harian, mingguan, bulanan, kuartalan (seberapa sering angka baru terbit; data bulanan bertanggal awal bulan dan terbit 2–6 minggu kemudian). Status: ok = segar · basi = lewat batas umur · ditahan = lompatan ekstrem menunggu konfirmasi · gagal = sumber error, data lama dipakai · mati = tidak diperbarui lama. Proksi: pengganti terdekat bila angka resmi tidak gratis. Label TERUKUR = angka dari sumber; DISIMPULKAN = hasil hitungan sistem; DIPUTUSKAN = tindakan.
Bukan saran investasi. Sumber: FRED, Yahoo Finance (yfinance), CFTC, DefiLlama, kalender mingguan. Sumber tidak resmi bisa berubah atau berhenti; itulah gunanya kolom status.
